# 🎓 Portal do Aluno SENAI

## 📖 Sobre o Projeto

O Portal do Aluno SENAI é um sistema web desenvolvido com o objetivo de facilitar o cadastro de alunos interessados nos cursos oferecidos pela instituição. Além de apresentar informações institucionais sobre o SENAI, o sistema disponibiliza recursos de acessibilidade para garantir uma melhor experiência aos usuários.

---

## 🚀 Funcionalidades

* Página inicial com informações institucionais.
* Cadastro de alunos.
* Validação de formulário em JavaScript.
* Máscaras para CPF e telefone.
* Feedback visual utilizando SweetAlert2.
* Carrossel de imagens.
* Tema escuro (Dark Mode).
* Modo Alto Contraste.
* Aumento e redução do tamanho da fonte.
* Integração com VLibras para acessibilidade em Libras.
* Layout responsivo utilizando Bootstrap 5.

## 📄 Cadastro de Alunos

O formulário realiza validações para:

* Nome completo.
* E-mail válido.
* Telefone completo.
* CPF formatado.
* Curso selecionado.
* Turno selecionado.
* Aceite dos termos.

Após a validação, uma mensagem de confirmação é exibida ao usuário.
